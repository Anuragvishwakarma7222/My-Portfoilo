PROJECTS









Automatic 5V Power Supply

An automatic 5V power supply is an electronic circuit or module designed to convert higher input voltages (such as 12V DC or 100-240V AC) into a stable, regulated 5V DC output without manual intervention





IOT Based Electric Induction

An IoT-based electric induction system integrates traditional induction motors or generators with Internet of Things technology, enabling remote monitoring, real-time data acquisition, and automated control. These systems use sensors (for temperature, vibration, voltage, current) and smart microcontrollers (like Raspberry Pi, Arduino, or ESP8266) to transmit data to cloud platforms





IOT Based Smart Cart Shopping Trolley

An IoT-based smart shopping cart/trolley is an automated retail solution using RFID, barcode scanners, and microcontrollers (e.g., NodeMCU) to identify items, calculate bills in real-time, and allow instant checkout via a display screen and mobile app. It eliminates long queues by automatically updating item lists and costs as items are added or removed, improving efficiency.
